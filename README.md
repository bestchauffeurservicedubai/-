# bestchauffeurservicedubai

Single-page, SEO-optimized luxury chauffeur website.

## Files
- `index.html` - main page (1000+ words, semantic headings, luxury dark + gold animated theme, inline SVG images, FAQ schema)
- `robots.txt` - allows all crawlers, points to the sitemap
- `sitemap.xml` - sitemap with the homepage URL
- `README.md` - this file

## SEO setup
- **Target keyword:** chauffeur service whatsapp booking dubai
- **Anchor text:** "chauffeur company dubai" -> https://www.facebook.com/PilotAndCars (only in the second paragraph, nowhere else)
- No phone number and no call button anywhere on the page

## Before publishing
Replace `https://bestchauffeurservicedubai.com/` with your real domain in:
- `index.html` (canonical and og:url)
- `robots.txt`
- `sitemap.xml`

Upload all four files to the site root.
